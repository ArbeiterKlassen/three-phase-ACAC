# ACDC 单半桥工程上板验收

本清单按“先断电检查、再限流预充、最后逐步加载”的顺序执行。任何一步不通过
都不要进入下一步。

## 1. 断电检查

- [ ] 确认功率半桥固定为 PC7=HI、PB0=LI；必须从驱动器丝印/原理图逐根核对，
      不能按排线方向猜测（现场已发生一次 HI/LI 对调，启动即蜂鸣并母线过压）。
- [ ] 万用表确认半桥高侧、低侧没有直通，母线电容已经放电。
- [ ] 确认 OLED 的 SPI3、DC、RES、CS 接线与旧板一致。
- [ ] 确认半桥中点连接 `Lb`，`Lb` 另一端连接 `Cf`，二极管桥方向正确。
- [ ] 确认 Cbus 极性、耐压和浪涌能力。
- [ ] 确认 Vcf 只走 PC5 一路，分压为高压端 48.4 kΩ、对地 1.9 kΩ。
- [ ] 确认 PC5 引脚电压在 0–3.3 V；该分压的 Vcf 理论满量程约 87.36 V。
- [ ] 确认 Vdc 仍为 PC4/ADC1_IN14。
- [ ] 确认 PC4 使用与 PC5 相同的 48.4 kΩ / 1.9 kΩ 分压，并且确实接 Cbus。
- [ ] 确认 PB1 保留给 TIM8_CH3N，不再接 Vdc 分压。
- [ ] 确认 PA0/PA1 没有新增用途。
- [ ] 确认原 PC0/PC1 电流、PC2/PC3 电压四路采样和接线完全没有改动。
- [ ] 确认 PA5 电流采样在零电流时约 1.68 V（旧 TA 标定零点约 2085 码）。
- [ ] 确认 PA6 BKIN 空闲为低，故障注入时为高。
- [ ] 用示波器/逻辑分析仪验证 PC7=HI、PB0=LI，且 PA7/PC6 未被驱动。

## 2. 静态 PWM 检查

先保持 `ACDC_HARDWARE_COMMISSIONED=0`，烧录后检查：

- [ ] PC7/PB0 没有持续有效的高侧/低侧驱动。
- [ ] MOE 为 0。
- [ ] PA6 拉高时 TIM8 Break 标志置位、MOE 被硬件清掉。
- [ ] 按键不会绕过 commissioning 锁。

之后临时把 `ACDC_HARDWARE_COMMISSIONED=1`，但**不接功率母线**，只接辅助电源，
用调试器或测试代码检查 20 kHz、互补、1 us 死区。不要用长时间 95% 占空比测试
自举驱动；本项目的最小低侧 5% 是为此预留的刷新窗口。

## 3. ADC 标定

断电接好采样后，逐路给已知值：

| 通道 | 建议检查点 | 要修改的位置 |
|---|---|---|
| Iin | 0 A、+2 A、-2 A | `g_acdc_cal_iin` |
| Vcf | 0 V、10 V、30 V、60 V | `g_acdc_cal_vcf` |
| Vdc | 10 V、30 V、60 V | `g_acdc_cal_vdc` |

不使用实验室源时不要凭“看起来差不多”改 gain。零点、比例、原始码窗口要一起
核对，特别是 `Iin` 的正负方向和 Cf 分压比。

Vcf 的默认标定值由代码中的电阻值自动计算：

```text
ratio  = 1.9k / (1.9k + 48.4k) = 0.037773
gain   = (3.3 / 4095) / ratio   = 0.0213341 V/码
```

电阻换型后只改 `ACDC_VCF_DIVIDER_LOW_OHM/HIGH_OHM`，仍应实测 0 V 和至少两个
正高压点确认比例。

## 4. 预充与首次启动

1. 交流源设 10–15 V RMS，限流设为 0.1–0.2 A。
2. 不按键，只上电。确认母线只经体二极管被动充电，没有大幅 LC 振铃。
3. 观察 `Vdc`，应接近输入峰值减二极管压降；若超过 66 V 立即断电。
4. 长按矩阵键盘 `#` 2 秒，状态从 `WAIT` 进入 `RUN`；PC13 可备用。
5. 先从 20–30 V 输入、空载开始，再逐步增加输入和负载。
6. 每次加载后检查 Iin 峰值，不能贴到 5.6 A OCP；31 V 满载只有约 3% 余量。

## 5. 需要记录的数据

- `Iin`、`Vcf`、`Vdc` 三路原始 ADC 与换算值；
- 半桥中点、两只门极、死区；
- `Vbus` 均值、纹波、软启动时间；
- 31/36/41 V 输入下的输入电流峰值；
- PF、THD、效率（如果有功率分析仪）；
- 故障注入结果：BKIN、输入过流、母线过压、拔掉 ADC。

## 6. 回滚条件

出现以下任一情况，立即断主电并回到 `ACDC_HARDWARE_COMMISSIONED=0`：

- 任何上下管同时导通的迹象；
- TIM8 的 MOE 被反复自动恢复；
- 预充时 Vbus 超过 66 V；
- 输入电流峰值超过 5.6 A 或测量先撞量程；
- 半桥中点出现不受控高频振荡；
- 高侧驱动电压跌落。
